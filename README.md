# Vicentekk

**Award-winning Meta Horizon Worlds Creator | AI-Assisted Developer | Live Event Production Specialist**

### Event & Workforce Management Application (private)

I built and deployed an internal full-stack application for a live-event company, using AI-assisted development with GitHub Copilot and Claude.

**Stack:** Next.js, React, TypeScript, Prisma, Turso/SQLite and Vercel.

**Areas covered:** event planning, staff assignments, compensation calculations, payment tracking, authentication, access permissions, reporting and audit history.

The application is private because it handles internal business processes and employee data. Its source code and production data are not publicly shared.
